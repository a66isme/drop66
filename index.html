Computer ⇄ phone, on the same Wi-Fi. Scan once, send both ways.

  1. Put both devices on the same Wi-Fi.
  2. Point your phone's camera at the code and open the link.
  3. Drop files on either device. They go to the other one.

Drop files here or tap to choose. They go to the other device.
    Not connecting?
    • Both devices on the same Wi-Fi, not mobile data.
    • A home network, not a guest, café, hotel or office one.
    • No VPN on either device.
    • On Windows, set the Wi-Fi to Private.
    • Keep both screens on while sending. Phones pause pages in the background.

    This page only introduces the two devices. Files go straight between them, encrypted, and are never stored on a server. Files over 100 MB ask you first, because the receiving browser keeps each file in memory until you save it.
